## พอร์ตของคุณ — `config/portfolio.json`
```json
{
  "holdings": [
    { "ticker": "PTT.BK", "shares": 1000, "avg_cost": 34.50 },
    { "ticker": "AAPL",   "shares": 10,   "avg_cost": 185.20 },
    { "ticker": "GC=F",   "shares": 0.05, "avg_cost": 3974.60, "name": "ทองคำ (oz)", "skip_xd": true }
  ]
}
```
- `ticker` — รูปแบบ Yahoo Finance: หุ้นไทยลงท้าย `.BK`, หุ้นเมกาใส่ symbol เปล่า
- `shares` — จำนวนหุ้นถือ (รวมทุก lot)
- `avg_cost` — ราคาทุนเฉลี่ย/หุ้น สกุลตามตลาด (฿ สำหรับ `.BK`, $ สำหรับเมกา)
- `name` — *(ไม่บังคับ)* ชื่อที่แสดงในตารางแทน ticker
- `skip_xd` — *(ไม่บังคับ)* ตราสารที่ไม่มีปฏิทินปันผลใน Yahoo เลย (ETF/ฟิวเจอร์ส เช่น `QQQM`, `GC=F`) ถ้าไม่ตั้งจะโดนเตือน "เช็ควัน XD ไม่ได้" ทุกวัน
- `skip_high_volume` — *(ไม่บังคับ)* ไม่ต้องเตือน High Volume สำหรับตัวนี้
- **ทองคำ** — ใช้ `GC=F` (ราคาต่อออนซ์ USD, นับเป็น USD แปลงบาทให้อัตโนมัติ), `shares` = จำนวนออนซ์ (oz). XAUUSD=X ถูกถอดจาก Yahoo แล้ว; GC=F เป็นฟิวเจอร์ส basis ต่างจากสปอตเล็กน้อย

## % เปลี่ยนราคา (1D / 1W / 1M)
- แสดงเป็นบรรทัดย่อยใต้ราคาของแต่ละตัว + สรุประดับพอร์ตในกล่องด้านบน
- คำนวณจาก **Adj Close** — วันขึ้น XD ราคาดิบจะตกเท่าเงินปันผล ถ้าใช้ราคาดิบจะดูเหมือนหุ้นร่วงทั้งที่ไม่ได้ร่วง
- 1W/1M เทียบด้วย**วันที่** (ย้อน 7 วัน / 1 เดือนปฏิทิน แล้วใช้แท่งล่าสุดที่ไม่เกินวันนั้น) ไม่ใช่นับถอยจำนวนแท่ง — ช่วงหยุดยาวจะไม่ทำให้ "1 สัปดาห์" กลายเป็นสองสัปดาห์
- จุดอ้างอิงคือแท่งล่าสุดของหุ้นตัวนั้นเอง ไม่ใช่วันนี้ — ตัวที่ราคาค้าง (เช่นกองทุนที่เทรดบาง) จึงยังเทียบถูกช่วง แต่ "1D" ของมันคือวันที่มีเทรดล่าสุด ไม่ใช่เมื่อวาน
- ประวัติไม่พอ (หุ้นเข้าใหม่) → แสดง `-` ไม่ใช่ 0
- ระดับพอร์ตใช้เรทวันนี้ทั้งสองฝั่ง จึงเป็นการเคลื่อนไหวของราคาล้วน ไม่รวมผลค่าเงิน

## Deploy
1. push ขึ้น GitHub repo
2. ตั้ง **Secrets** (Settings → Secrets and variables → Actions):
   - `RESEND_API_KEY` — จาก resend.com (free 3,000/เดือน)
   - `REPORT_TO_EMAIL` — อีเมลปลายทาง
   - `REPORT_FROM_EMAIL` — *(ไม่บังคับ)* ดีฟอลต์ `onboarding@resend.dev` ตอนทดสอบ
3. แท็บ Actions → *Daily Stock Report* → **Run workflow** เพื่อทดสอบ
