# .notes/

บันทึกความรู้ของโปรเจกต์ (plan, สถานะฟีเจอร์, decision ที่ควรอยู่ยาว) — **plan ทั้งหมดเก็บที่นี่ ไม่ใช่ `~/.claude/plans`**

- `<feature>.md` — หนึ่งไฟล์ต่อหนึ่งฟีเจอร์ (decision, สถานะ, งานค้าง)
- `sessions/` — ไม่ใช้โดยปกติ; เก็บเฉพาะเมื่อผู้ใช้ขอสรุป session ชัดเจน

## ฟีเจอร์
- [summary-alert.md](summary-alert.md) — ระบบส่งเมลสรุปพอร์ตรายวัน รวมมูลค่า, P/L, momentum, XD และข้อมูลซื้อขายกรรมการ/ผู้ถือหุ้นใหญ่จาก ก.ล.ต.
- [price-trend.md](price-trend.md) — % เปลี่ยนราคา 1D/1W/1M รายตัวและระดับพอร์ตในเมลรายวัน
