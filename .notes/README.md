# .notes/

บันทึกความรู้ของโปรเจกต์ (plan, สถานะฟีเจอร์, สรุปงานแต่ละ session) — **plan ทั้งหมดเก็บที่นี่ ไม่ใช่ `~/.claude/plans`**

- `<feature>.md` — หนึ่งไฟล์ต่อหนึ่งฟีเจอร์ (decision, สถานะ, งานค้าง)
- `sessions/YYYY-MM-DD-<topic>.md` — สรุปงานต่อ session (เขียนไฟล์ใหม่ทุกครั้ง ไม่ทับของเก่า)

## ฟีเจอร์
- [daily-alert-v1.md](daily-alert-v1.md) — ระบบส่งเมลสรุปพอร์ตรายวัน (v1: มูลค่ารวม, P/L, momentum, XD)
- [sec-insider-filings.md](sec-insider-filings.md) — เลื่อน cron เป็น อ–ส + เพิ่มข้อมูลซื้อขายกรรมการ/ผู้ถือหุ้นใหญ่ (แบบ 59/246-2 จาก ก.ล.ต.)
